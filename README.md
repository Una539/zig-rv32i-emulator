# RV32I Emulator
一个用 *Zig* 实现的RV32I模拟器，运行裸机程序。

## 开发方式
这个项目使用 *娱乐化编程* 而不是传统工程项目，因此不讲究良好的代码文件拆分，也不需要良好的文档以及极其全面的测试，写着玩的，快乐至上。

## 知识准备
本人有开发经验，但是无任何 *Zig* 和 *RV32I* 的知识准备，有编程基础，但不是精通的人。

## 技术细节
装载 RV32I 裸机 ELF，按其入口地址开始执行；
提供从 0 开始的 1 MiB 内存，sp 初始为 0x00100000；
裸机程序完成后进入无限循环，并保持结果在 x10；
Ctrl+C 停止模拟器并查看 x10。
